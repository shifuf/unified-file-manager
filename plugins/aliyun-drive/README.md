# 阿里云盘存储插件

纯 Node.js 22+ / TypeScript 插件。通过阿里云盘网页扫码协议登录，不依赖 Python。

## 安装与连接

1. 构建：仓库根目录执行 `npm run build:plugin-sdk` 和 `node plugins/build.cjs aliyun-drive`。
2. 在「存储配置 → 插件管理」上传 `ALIYUN_DRIVE-1.3.0.zip`。
3. 新增全局存储配置，选择「阿里云盘」，填写名称，点击扫码连接。
4. 使用阿里云盘 App 扫码确认，选择资源盘或备份盘。保存目录 ID 默认为 `root`。
5. 测试连接会上传探测对象并确认云端元数据，然后删除探测对象。保存后，超级管理员可点击「云端文件」浏览保存目录中的已有内容。

1.3.0 起，带项目上下文的新上传对象直接保存在指定根目录下的「项目名称-稳定短标识」目录。名称中的路径及特殊字符会被替换，目录长度受限；同名项目以项目 ID 的 SHA256 短标识隔离。项目改名后沿用已有目录，以云端隐藏标记 `.ufm-project.json` 和加密缓存识别，不创建另一份对象。标记只保存项目 ID、名称及云盘根目录校验范围，不含账号凭据；云端列表隐藏该标记。没有项目上下文的系统备份继续使用 `UFM-objects-…` 目录。

内容仍以不可变 key 的确定性哈希名保存。1.2.0 起每个新对象附加 `.ufm.json` 描述，保存原始名称、对象 key、大小和校验值；1.3.0 的新描述还可保存项目身份和安全的相对目录 `folderPath`。页面读取通过校验的描述显示原名和路径。请保留内容、描述及项目标记，不要手工修改。旧对象仍可浏览和读取；缺少原数据库或描述时，不能由哈希名推导原始名称。

同一不可变 key 和内容再次上传时沿用首次验证的描述；业务文件后续重命名不会改写该历史对象的原始名称，也不会阻止副本任务重试。

为已有副本再次同步并传入项目身份时，先交叉校验本地 SHA256、云端大小和 SHA1，再通过网盘 `/v3/file/move` 移动内容及已验证描述，保持对象 ID、key、文件字节和首次原名。整理不删除云端对象。旧描述保持原样；移入项目目录后可从项目标记识别所属项目。移动失败会使任务失败，部分移动可在下次重试时继续；未知归属对象继续保留原处。

## 跨部署浏览与拉取

不同部署连接同一账号、云盘和保存根目录后，可在「云端文件」中进入已有目录、分页查看、下载，或选择文件拉取到本部署项目。它们不需要共享插件的本地对象映射；各部署的项目、文件索引、备份记录和登录账号仍各自由数据库保存。已有系统备份可选择「导入备份管理」，校验归档后生成本地备份记录，不会自动恢复或覆盖数据库。

页面支持文件和目录单选、多选、全选当前页及同步当前目录，最多同步至 20 个目标项目。递归枚举限制为 2000 个文件、64 层目录；枚举完整后才开始写入，保留安全的相对目录。页面逐文件顺序提交，同一个文件只下载校验一次后写入各目标项目；API 仍支持每批最多 20 个源文件。下载与拉取会校验云端大小和 SHA1；普通拉取还受本地上传限制、项目配额和主机临时文件上限约束。主机默认单文件上限为 512 MiB，可通过 `REMOTE_FILE_MAX_BYTES` 配置。备份归档沿用系统的 256 MiB 限制。

页面使用后台取回任务与短轮询，避免慢速云盘传输超过反向代理的等待时限。新请求前刷新源文件所在分页，并核对最初选择时的大小、哈希和名称；同一批次的校验依据在读取前固定。网络暂时中断后重试会继续查询已有任务。下载校验完成后显示一次性的保存链接；每个用户最多保留 3 个待保存文件，10 分钟无人领取会自动清理。已完成的导入结果最多暂存 10 分钟，容量达到 128 项时优先回收最早完成的导入结果；运行中的任务和待保存下载不会被回收。取回任务不跨 API 重启恢复，重启或过期后需重新选择；相同内容导入复用已有文件。

「上传同步」可单选或多选已分配的项目，后台副本任务仅整理所选存储。任务会等待所需目标副本就绪后才显示完成；失败项可在任务管理重试。新上传和可确认归属的旧对象按项目名称整理，未知对象不会被猜测归类。

丢失本地对象映射后，插件只在保存根目录内的旧 `UFM-objects-…` 目录和标记有效的项目目录中按 key 查找，检查父目录归属，最多扫描 256 页、20000 条记录及 64 层目录。重复对象或项目标记、循环分页和超限均显式失败，不猜测应覆盖或删除的对象。更换部署生成不同本地账号 ID 时，项目标记及旧目录仍可识别。同一 key 在多个目录存在副本时，需要管理员检查歧义后再操作。

单个文件的下载时限默认为 30 分钟，以适应云盘限速。主机可通过 `REMOTE_FILE_TIMEOUT_MS` 调整，范围为 1000–1800000 毫秒；超时会清理未完成的临时文件，可刷新后重试。

## 数据与恢复

账号令牌、设备密钥与对象映射由宿主加密保存在 `STORAGE_PLUGIN_DIR/state/ALIYUN_DRIVE`。插件升级保留状态。备份时应同时保存此目录、数据库、存储配置和原 `APP_CRYPTO_KEY`。丢失加密密钥后不能解密账号状态。

令牌失效时编辑配置并重新扫码，必须使用原账号。已有配置不允许更换账号、云盘或保存根目录，需要更换时新建配置并迁移文件。账号仍被配置引用时不可解除绑定。

业务删除进入系统回收站，远端对象保留；确认彻底删除后仅删除对应对象及其描述，不清空网盘回收站。阿里云盘仍作为备份存储，不加入业务文件自动预览、历史版本或副本下载路由；管理员可通过「云端文件」显式取回。上传完成后用云端文件状态、大小及 SHA1 元数据与加密保存的源 SHA256 映射交叉确认；映射存在时只读元数据。映射丢失时可下载最多 16 KiB 且验证 SHA1 的描述恢复校验映射，项目标记同样受此上限约束；这些确认不代表下载业务内容并重新计算 SHA256。没有映射也没有有效描述的早期对象可按 key 查找或删除，但需重新上传校验后才能确认备份。

## 验证边界

协议测试使用受控传输验证扫码状态、流式上传下载、并发刷新和对象生命周期。真实服务的二维码生成可在未登录时验证；登录确认、网盘权限、设备会话和实际上传下载必须使用用户本人账号完成。网盘接口变化时插件可能需要更新。

实现参考了 aligo 项目描述的接口行为，未包含 Python 代码。设备 ECDSA 使用 MIT 许可的 `@noble/curves`；打包保留依赖法律声明。
