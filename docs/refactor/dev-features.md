# 统一文件管理系统 · 开发功能文档

> 一句话：**把任意存储（本地/七牛/又拍云/阿里云/任何 S3 兼容）变成你自己的文件分发平台** —— 上传、管理、分享、统计、防刷，一条龙。
> 本文档 = 产品功能需求清单 + 每个功能的行为规则。开发按此逐条实现即可，不涉及技术栈细节。
> 目标环境：2核2G 低配 VPS，轻快、省内存。

---

# 1. 项目与存储

## 1.1 项目（文件空间的隔离单位）
- 可创建多个项目，项目之间文件、统计、配置完全隔离
- 每个项目可以：
  - 单独设置绑定的存储
  - 单独设置文件容量上限（GB）和文件数量上限
  - 单独设置允许访问的域名白名单
  - 单独开关：站内通知、公开文件库、WebDAV
- 项目支持导出（打包全部元数据和文件）和导入恢复
- 项目删除先进回收期，到期才真正清除

## 1.2 存储方式（核心能力 1️⃣）
一个系统同时支持以下存储，**可同时添加多个、随时切换**：

| 存储类型 | 说明 |
|---|---|
| 本地磁盘 | 服务器自身磁盘，默认存储 |
| 七牛云 | 填 AK/SK + 桶名 + 加速域名 |
| 又拍云 | 填操作员/密码 + 服务名 + 加速域名 |
| 阿里云 OSS | 填 AK/SK + Bucket + Endpoint |
| **AWS S3 兼容** | 一个适配全家：AWS S3 / MinIO / Cloudflare R2 / 腾讯云 COS S3 兼容接口 / Backblaze B2 / 任何实现 S3 协议的存储。填 AccessKey/Secret/桶/Endpoint/区域即可 |

- 每个存储配置：
  - 连接信息加密保存，界面上永远不显示明文密钥
  - 保存前可一键"连通测试"（自动验证：能否上传测试文件、能否下载、加速域名是否生效）
  - 可设置优先级顺序（数字越小越优先）
  - 可设为某项目的默认存储或全局默认存储
- **存储用量显示**：
  - 优先从平台 API 实时读取（已用空间/已用流量/总额度）
  - 平台不提供的显示"未知"，绝不能把未知显示成 0 误导用户
  - 允许手动填入用量数字（标注"手动填报"来源）
- **流量/空间超额自动切换（故障切换）**：
  - 每个存储可配置：空间额度、流量额度、触发阈值百分比（默认 90%）、是否自动切换
  - 当当前存储用量达到阈值 → 自动把项目切换到优先级列表里下一个可用存储
  - 切换同时自动创建后台迁移任务，把旧存储上的文件分批搬到新存储（见 §8）
- **跨存储复制**：任意文件可手动复制到另一个存储；复制完成后文件归属切到新存储，旧存储对象保留（回滚保险）

## 1.3 上传直传（S3 兼容直传）
- **S3 兼容协议直传**：对 AWS S3 / MinIO / R2 / COS S3 兼容接口，系统生成预签名 PUT URL（大文件用 Multipart 分块预签名），浏览器/客户端**直接把文件传到存储**，不经过应用服务器（不占服务器带宽和流量）
  - 传完客户端回调系统"确认完成"，系统验证对象真实存在、大小一致后才登记入库
- 七牛/又拍云同理：系统生成各家的上传凭证（uptoken / form 签名），客户端直传
- 本地存储走服务器中转
- **统一行为**：无论哪种存储，前端上传代码完全一致（同一个接口拿到"往哪传、带什么凭证"），换存储不用改客户端

# 2. 文件上传

- 网页上传：点选 + 拖拽 + 整个文件夹上传，多文件并行，实时进度条，失败单个重试
- 大文件分块上传：自动切块（默认 5MB），逐块传，支持查询已传块（断点续传）、暂停、取消
- 分块 + 直传兼容：分块模式在 S3 兼容存储上使用 Multipart Upload（同一套预签名机制）
- 上传凭证（给第三方/访客用）：
  - 可生成"上传令牌"：限定目录、限定文件类型、单个大小上限、总数量上限、总容量上限、有效期
  - 拿令牌的人可通过网页或 API 直传到指定目录，全部计入项目用量与配额
- 上传时系统自动完成：
  - 识别文件类型（图片/文档/视频/音频/压缩包/代码/其他）
  - 计算内容指纹（用于秒传和完整性校验）
  - 生成图片缩略图 + WebP 版本
  - 视频自动转码：720P MP4 + 多码率 HLS（可流畅拖动）+ 封面图（worker 进程处理，不占主服务内存）
  - 提取文本内容（供全文搜索）
  - 重名文件自动保留旧版本（版本历史）
- 秒传：项目内已存在相同指纹的文件时，新上传瞬间完成（不重复占用空间）
- 超出项目配额：明确报错"空间/数量已满"，且可配置触发通知

# 3. 文件管理（前端体验重点）

- **系统树视图**：左侧 Windows 资源管理器风格的目录树（展开/折叠/右键菜单/拖拽移动），主区域联动
- **虚拟滚动**：文件列表/网格虚拟渲染，10 万级文件滚动不卡顿
- 列表视图 + 缩略图网格视图切换
- 筛选：按类型/标签/备注/目录/状态（正常/回收站）组合筛选
- 全文搜索：能搜到**文件内容里的文字**（不只是文件名）
- 文件操作：
  - 改名 / 移动（单个与批量）/ 复制（同项目与跨存储）/ 打标签 / 写备注 / 设公开私有
  - 版本管理：覆盖上传自动存历史版本，可查看、对比、一键回滚
  - 回收站：删除可恢复；到期自动彻底删除；支持批量恢复/彻底删除
- **悬停操作（可调教）**：鼠标悬停在文件行/卡片上浮现操作按钮条，按钮集合可在设置里自定义（顺序/显隐），高频操作一键直达
- **个人工作台**：登录后首页为工作台——最近文件、我的分享、常用目录、下载趋势卡片，可自定义卡片布局
- 在线预览：
  - 图片（缩略图 → 原图）、视频（HLS 流播放 + MP4 备选）、音频、PDF
  - Office 文档（Word/Excel/PPT）对接外部预览服务（KKFileView / OnlyOffice，地址可配置）
  - 文本/代码高亮预览
- 文件详情：大小/类型/上传时间/指纹/所在存储/是否走加速/下载次数/版本历史/引用的分享列表

# 4. 分享与分发（核心能力 2️⃣）

## 4.1 分享直链
- 每个文件可生成**直链**（复制即用，可直接 <img>/<video> 引用或浏览器打开下载）
- **直链域名可自定义**：
  - 使用该文件所在存储绑定的加速域名（如 qn.shifuf.com / yp.shifuf.com）
  - 或系统统一的自定义下载域名（在系统设置里配置）
  - 未配置任何域名时自动用当前访问域名兜底
- 直链可控性：
  - 直链是否公开可随时开关（关闭后直链 403）
  - 直链可带 Referer/Origin 防盗链白名单（系统级+项目级两层）
  - 直链可带过期签名（生成"限时直链"，到期自动失效，适合临时分发）
- 目录公开：把整个目录设为公开，目录内所有文件自动获得直链，支持批量发布/取消

## 4.2 分享页（带控制权的分发）
- 文件分享页：访问链接（随机码或自定义短路径，如 /s/readme）
  - 可设置：访问密码、有效期、最大下载次数、允许 IP 列表、下载限速（超频触发限流）、水印文字、仅预览（禁止下载）
  - 分享状态实时可见：生效中 / 已过期 / 下载次数已用完 / 已手动停用
  - 随时编辑规则或停用
- 目录分享页：分享一个文件夹，访客可浏览文件列表并逐个下载（规则同上）
- 公开文件库：项目级对外页面（可自定义地址路径），浏览/搜索/下载项目内公开文件

## 4.3 分享页自定义（核心能力 2️⃣）
**分享页外观全部可自定义**（系统设置里配置，对所有分享页生效）：
| 可自定义项 | 说明 |
|---|---|
| 品牌标题 | 分享页顶部大标题 |
| 副标题 | 标题下的一行说明文字 |
| Logo 图片 | 顶部 Logo（支持外链图片地址） |
| 主题色 | 按钮/链接主色 |
| 页面背景 | 纯色或渐变色 |
| 内容卡片背景 | 中间文件卡片底色 |
| 页脚文案 | 底部自定义文字 |
| "Powered by" 署名 | 显示/隐藏 |
- 所有项留空 = 使用默认样式（不显示品牌区）
- 分享页自动适配手机端

## 4.4 访客体验与隐私
- 访客打开分享页看到：品牌区（如有）→ 文件卡片（名称/大小/类型/预览）→ 下载按钮
- 有密码的分享先显示密码输入框
- 设置了水印的，预览图和页面叠加半透明水印
- **隐私保证**：访客页面和接口响应中永远不出现内部信息（用的哪家存储、存储桶名、内部文件路径、是否走加速）——这些只有管理员后台能看到

# 5. 下载

- 所有下载支持断点续传（Range），视频可拖动进度条
- 云存储上的文件下载默认 302 跳转到带签名的直链（不消耗服务器流量）
- 本地文件、有密码/限速的分享走服务器流式输出
- 下载限速：按 IP 计数（默认同一 IP 对同一分享 10 分钟 60 次），超了触发限流
- 下载记账（每一次下载都记录）：时间、来源渠道（后台/分享/公开/API/WebDAV）、IP、浏览器、Referer、文件、大小、成功与否
- 日汇总报表：按天/项目/文件/渠道聚合次数和流量；项目统计图表、下载 TOP 榜

# 6. 防刷与 IP 管理

- 自动限流：超频 IP 被限流并记录事件（可推送告警）
- IP 台账：每个 IP 的累计下载、被限流次数、最近下载的文件与分享
- IP 封禁：临时封（到时自动解）或永久封，可填原因和备注；一键解封
- 封禁后该 IP 的所有分享/公开下载直接 403

# 7. WebDAV

- 每个项目可独立开启 WebDAV，配独立账号密码
- Windows 资源管理器 / macOS Finder / RaiDrive / Cyberduck 等可直接挂载为网络磁盘
- 支持完整操作：浏览、上传、下载（断点续传）、新建目录、删除、移动、复制、重命名、文件锁
- WebDAV 的上传下载计入项目配额与下载统计

# 8. 文件迁移（存储切换的后台保障）

- 触发方式：① 故障切换自动创建 ② 手动"本地文件一键上云" ③ 手动把某些文件迁到指定存储
- 迁移过程：后台分批（每批 50 个）复制 → 校验 → 更新归属，**原存储对象保留**
- 任务能力：实时进度百分比、失败文件清单、暂停/继续/取消/失败重试
- 可靠性：服务重启自动续跑；worker 进程独立执行，不拖慢主服务

# 9. 消息通知

- **站内信**：系统事件自动生成站内消息（红点计数、可标记已读、点击跳转）
- **外部推送**：对接自建推送服务（地址+API Key），事件可勾选：文件上传/删除/分享下载/限流触发/配额超限/存储故障；支持发测试消息；同类事件短时聚合不轰炸
- **出站 Webhook**：向你的业务系统 POST 事件通知（带签名可验真），有投递记录（成功/失败/状态码）和测试功能

# 10. 备份与恢复

- 手动一键全量备份：整个数据库 + 可选把存储里的实际文件一起打包
- 备份包自带完整性校验（防篡改），可下载保存
- 一键从备份包恢复整个系统；也支持导入外部备份 zip
- **WebDAV 远端备份**：
  - 配置远端 WebDAV（地址/账号/密码），可测试连通
  - 每天定时自动全量备份并上传到远端
  - 自动按保留份数清理旧备份
  - 界面列出远端所有备份，可一键恢复
  - 手动备份时自动同步上传一份到远端

# 11. 生命周期与自动化

- 生命周期策略：对某目录/某类文件设置"N 天后自动清理"，可开关、可手动立即执行
- 定时任务自动处理：回收站到期清理、备份、用量刷新、临时数据清理（worker 执行）

# 12. 审计与安全

- 审计日志：80+ 种敏感操作全留痕（谁/何时/IP/浏览器/详情），可筛选、导出 CSV、按保留策略清理
- 登录安全：密码错误锁定、TOTP 两步验证、会话管理（踢设备）
- 接口安全：第三方 API 签名鉴权 + 防重放；上传凭证鉴权
- 防攻击：SSRF 防护、上传内容嗅探、压缩包炸弹防护、路径穿越防护
- 密钥存储加密、界面脱敏

# 13. 第三方 API（OpenAPI）

- 应用凭 AppID + 签名（防伪造）+ 时间戳（防重放）调用
- 开放能力：上传（中转/直传/凭证）、下载、删除/恢复、信息修改、目录管理、目录树、搜索、分享创建/编辑/停用、版本查看/回滚、配额查询、批量回收/恢复
- 内置开发者对接文档页（含密钥管理）

# 14. 系统设置

- 全局配置：单文件大小上限、单次上传数量、回收站保留天数、强制 HTTPS、防盗链域名白名单、Office 预览服务地址、自定义下载域名
- 分享页自定义（见 §4.3）
- 悬停操作自定义（见 §3）
- 工作台卡片自定义（见 §3）
- 系统健康面板：数据库/各存储连通状态一目了然
- **在线检查更新**：显示当前版本和最新版本，一键检查，发现新版醒目提示；更新源地址可配置（默认国内可直连）

# 15. 全文搜索

- 上传时自动提取文档内容，分词后写入数据库全文索引（不引入独立搜索引擎，省内存）
- 管理端搜索和公开库搜索都支持"搜内容"
- 中文分词友好（支持中文词组匹配，不是简单 LIKE）

# 16. 部署与运维

- Docker 部署：PostgreSQL + API + Worker 三个容器，数据全部落持久卷（更新不丢数据）
- 内存预算可控：API 与 worker 分进程限制内存，2核2G 可跑
- 多架构镜像（x86/ARM）
- **服务器一条命令更新**：`bash release-update.sh` 自动完成"检测新版本 → 下载配置 → 拉镜像（自动尝试国内镜像源）→ 重建容器 → 健康检查 → 输出验证地址"
- 版本发布全自动：推代码 → CI 自动构建镜像 → 服务器一条命令更新
