# 下载与历史版本

又拍云下载可以使用已配置的 CDN 域名。文件记录有 SHA256 时，下载先通过 CDN 读取并验证完整内容；CDN 不可用或校验不符时回到源站。上传后的确认始终读取源站，避免把 CDN 缓存误当作上传成功。

完整非 Range 下载在 CDN 内容校验成功后，可直接交给浏览器从又拍云下载，减少服务器公网转发的速度限制。管理页面先从同源接口读取下载来源及 CDN 地址，再发起浏览器下载；CDN 不可用时，同一次请求返回已校验的文件流。附件下载保留原文件名，公开预览保持 inline 行为。

Range、图片转换、水印、显式流式下载及上传/复制/历史恢复确认继续使用验证后的文件流。Range 在首次读取前关闭跳转，复用已经验证的内容，避免重复读取。完整内容验证仍可能影响首字节等待时间；实际速度受客户端和 CDN 网络影响，不能保证达到控制台测速结果。

一次分享下载的同一下载会话只记录一次下载计数和审计。浏览器断点续传、重复 Range 不会新增记录；用户发起新的下载会话会独立计数。审计中的下载来源可以区分 CDN 与源站。

每个文件保留最新三个历史版本，当前版本单独保留。保存内容、覆盖上传及 WebDAV 覆盖会应用保留规则。超额历史版本的源对象和副本全部删除成功后，才删除历史记录；仍被当前文件、保留版本或其他文件引用的对象不会删除。

DAV 删除和彻底删除开始后，文件进入持久的删除状态。存储故障时会报告失败，文件保留在回收站供重试；删除尚未完成的文件不能恢复或覆盖，以免返回已被部分删除的内容。并发写入不能绕过这个状态。

拖拽普通文件继续使用现有上传流程。云存储的日期目录是对象存储路径，与文件管理页面中的逻辑文件夹分别管理；本次未修改目录布局。

部署可通过 `API_RUNTIME_IMAGE` 指定已经验证的 API 运行时镜像，并设置 `API_RUNTIME_PREPARED=true`。构建先确认 OpenSSL、FFmpeg 和 su-exec 可用，再清除继承的 API 代码与依赖并装入本次编译结果。通常构建保持默认参数；复用时固定一个基础镜像 digest，避免连续把上一轮 API 镜像作为基础而叠加镜像体积。

构建阶段也可通过 `BUILD_RUNTIME_IMAGE` 指定固定运行时镜像，并设置 `BUILD_RUNTIME_PREPARED=true`。构建会确认 Node、npm、OpenSSL 可用，清除继承的编译产物后重新安装含开发工具的工作区依赖。API 与 Web 构建均可使用；默认仍基于 `NODE_IMAGE` 安装 OpenSSL。该选项不改变最终 Web 镜像的 Nginx 基础层。
