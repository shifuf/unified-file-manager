# WebDAV 上传修复与自定义地址

## 目标

修复 DAV PUT 的 uploadedById 外键失败；项目 DAV 地址支持纯英文、纯数字或两者组合，空白时自动生成随机后缀。

## 行为

- 项目编辑界面增加“DAV 地址后缀”，长度 1–64，仅英文字母和数字，统一保存为小写。显示最终 `/api/dav/<后缀>`，空白提示“保存后随机生成”。
- 新建／首次设置时未填写，生成 24 位密码学随机十六进制后缀；已保存后缀随普通编辑保留。主动清空并保存时重新生成。
- 全局唯一，包含已删除项目以避免恢复冲突；不能占用其他项目的 ID。重复自定义地址返回 409 并在页面显示，不覆盖其它项目。
- 推荐保留原 `/api/dav/<项目ID>` 地址兼容已有客户端；新后缀与原 ID 均需原 DAV 凭据，解析后始终限定实际项目。改后缀后旧自定义后缀失效，原 ID 地址继续可用。
- 既有启用项目通过迁移获得随机后缀；禁用／回收项目的 DAV 地址不可访问。
- PROPFIND href、COPY／MOVE 的 Destination、LOCK 等都使用本次请求入口，不能混入其他项目。网页展示统一 `files.shifuf.com`。
- DAV 账号是项目级凭据，不是 User。新文件 uploadedById 保持空值；审计、事件、配额和下载记录继续使用 `webdav:<用户名>` 标识。不给不存在的用户补造记录，不改变 DAV 密码。

## 验证和发布

先复现外键失败并添加回归；覆盖字母／数字／混合／空白随机、冲突、保留与清空、旧 ID 兼容、跨项目 Destination 拒绝、认证和删除项目隔离。真实本地与公网测试 MKCOL、PUT、GET、HEAD、Range、覆盖、PROPFIND、MOVE／COPY；保留新验收文件。用户提出的 sub 目录仅在确认空目录时清理。

v0.2.1 已完成 GitHub 推送、CI 镜像发布、服务器切换和 12 个切换前有效文件校验。本次后续修复发布为 v0.2.2，保留已发布标签，新建备份后只更新 API／Web。
